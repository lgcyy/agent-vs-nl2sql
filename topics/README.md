# 专题综述

围绕一个问题，综合多篇论文与其他资料，整理已有结论、方法差异与尚未解决的问题。

[返回首页](../README.md) · [专题模板](../templates/topic.md)

## 候选整理方向

| 方向 | 关注内容 | 状态 |
| --- | --- | --- |
| 专精能力与通用能力 | 能力保持、迁移、遗忘与任务关系 | 待整理 |
| 数据混合与训练方法 | 数据选择、配比、样本长度、训练顺序与相关方法 | 待整理 |
| Agent 轨迹质量 | 可靠性、质量检测、筛选、清洗与过程监督 | 待整理 |

这些方向尚无对应的完整综述。形成文档后，在本页添加相对链接。

## 整理方式

按“问题是什么—已有工作解决了什么—采用什么方法—还有哪些局限与新问题”组织内容，引用相关论文笔记和原始来源。

建议文件名：`topic-name.md`。主题随资料积累调整。

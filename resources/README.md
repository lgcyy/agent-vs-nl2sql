## 记录方式

- 说明资源提供什么内容，以及它与调研主题的关系。
- 优先保留作者、项目维护者或官方发布的原始链接。
- GitHub 项目可按需记录维护情况、版本和星数，并注明核查日期。
- 技术文章和社区讨论需区分作者观点与有原始证据支持的结论。
- 论文官方代码可直接链接对应论文笔记，避免重复维护。
- 值得详细整理的资源可另存为 `resource-name.md`，再从本页链接。
